REPOSITORIO DE ATUALIZACAO DA SINTONIARP

Estrutura: data/ (arquivos do jogo), config.json, tools/gerar_update.py, update.json (gerado sozinho).

ATUALIZAR A DATA (arquivos do jogo)
1. Coloque/troque os arquivos dentro de data/ mantendo as mesmas pastas do jogo no celular.
2. Faca commit/upload no GitHub (pode ser pelo site: Add file > Upload files).
3. O GitHub Actions gera o update.json sozinho. Na proxima vez que o player abrir o launcher, baixa so o que mudou.

ATUALIZAR O APK
1. Aumente versionCode no app/build.gradle do source e compile com a MESMA keystore.
2. No GitHub: Releases > Draft a new release > envie o arquivo com o nome SintoniaRP.apk.
3. Edite config.json (versionCode igual ao do APK novo, versionName, notes, force: true = obrigatorio) e faca commit.

Observacoes
- O GitHub raw demora ate uns 5 minutos para refletir mudancas.
- Limite do GitHub: 100 MB por arquivo dentro do repositorio (data/). Arquivos maiores: use Release ou o sintoniarp.zip (dataZipUrl no config.json).
- Teste rodando "python3 tools/gerar_update.py" no PC para ver o update.json.
